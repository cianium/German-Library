# German Library — Organic Theme & Mobile Article Studio (Incremental Preview)

## هدف

این نسخه یک تغییر محدود روی v3.1.0 موجود است، نه تکمیل یا جایگزینی الزامات V7.5. Learning Roadmap، Book Package، ساختار داده کتاب‌ها و گردش‌کار انتشار مقاله حفظ شده‌اند.

## طراحی

- Light Theme پیش‌فرض برای بازدیدکنندهٔ جدید: کاغذ گرم `#f8f5ee`، سفید گرم `#fffdf8`، سبز جنگلی `#385b40` و نقطهٔ تأکیدی سفالی.
- Dark Theme اختیاری: زغالی سبز `#1d241f` با CTA به رنگ سبز روشن.
- انتخاب قبلی کاربر برای تم در localStorage حفظ می‌شود (کلید موجود `gl_theme_v73`).
- متن‌ها، لینک‌ها و CTAهای اصلی کنتراست قابل قبول دارند؛ از گرادیان/شدوهای تزئینی سنگین استفاده نشده است.

## استودیوی نویسنده در گوشی

- نمایش سه حالت «نوشتن»، «سئو»، «انتشار» در عرض‌های کمتر از ۹۰۰ پیکسل؛ دسکتاپ تمام بخش‌ها را نمایش می‌دهد.
- ابزارهای متن: پاراگراف، Bold، Italic، H2، H3، دو نوع لیست، نقل‌قول، درج لینک HTTPS، درج تصویر با Alt، خط جداکننده، حذف قالب، Undo و Redo.
- پیش‌نمایش تقریبی نتیجه جست‌وجو، تعداد کلمات و زمان تقریبی مطالعه.
- Focus Query اختیاری؛ بررسی طبیعی بودن حضور آن در عنوان، تیتر، مقدمه و Meta Description. هیچ وعده‌ای درباره رتبه گوگل یا امتیاز قطعی SEO داده نمی‌شود.
- افزودن پیوند/تصویر با فرم dialog قابل لمس به جای prompt مرورگر؛ محل انتخاب متن در زمان لمس نوار ابزار بهتر حفظ می‌شود.
- خطای قدیمی «غیرفعال شدن فرم هنگام ایجاد مقالهٔ جدید توسط Author» اصلاح شد. در همچنان برای رکوردهای متعلق به دیگران مجوز تغییر نمی‌کند.
- امکانات موجود: Draft، autosave با کنترل revision، Workflow بررسی و انتشار، Private Preview و revision history حفظ شده‌اند.

## محدودیت‌ها و موارد بعدی

- ویرایشگر فعلی `contenteditable` و `execCommand` دارد؛ این روش سبک و سازگار با کد فعلی است ولی هم‌سطح موتور کامل Microsoft Word نیست. برای همکاری همزمان، جدول‌های پیچیده، بازچینی عکس و پشتیبانی کامل از IME می‌توان بعداً یک editor-engine تخصصی را ارزیابی کرد.
- درج تصویر از URL HTTPS عمومی پشتیبانی می‌شود؛ آپلود مستقیم از گالری موبایل به جریان امن Storage و تأیید/انتشار فایل نیاز دارد و در این تغییر اضافه نشده است.
- طراحی Article Studio بدون تنظیمات واقعی Auth/Supabase قابل مشاهده است، اما ذخیره و انتشار عملیاتی نیازمند پیکربندی و آزمون روی یک پروژهٔ واقعی Supabase است.
- اختلاف فعلی ناوبری ۵ مقصدی v3.1 با سند چهار مقصدی V7.5 عمداً در این اصلاح محدود تغییر داده نشده است. Articles می‌تواند در فاز یکپارچه‌سازی navigation زیر Extras قرار گیرد.
- کاورهای واقعی، اصلاح مدل CEFR چندسطحی، جست‌وجوی یکپارچه و توسعهٔ Admin خارج از این patch هستند.

## QA

- `npm run qa` و `npm run build && npm run verify:dist`
- smoke testing با Chromium در اندازهٔ ۳۹۰ پیکسل برای نویسندهٔ Mocked: ایجاد مقاله، تغییر پنل، SEO، درج لینک مجاز/نامجاز و نمایش Light/Dark، بدون JavaScript error یا horizontal overflow.
- آزمون عملی بارگذاری تصویر، Autosave آنلاین، کنترل دسترسی واقعی، Sync و انتشار Vercel همچنان نیازمند محیط متصل هستند.
