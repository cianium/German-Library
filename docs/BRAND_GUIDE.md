# Lexipfad — brand quick guide

**Name:** Lexipfad (Lexi[kon] + Pfad = “word path”). Tagline in the logo: *Deutsch lernen*.
Write it with a capital L, one word, Latin script, also inside Persian text (it renders LTR).

## Palette (sampled from the logo)
| Role | Hex | UI use |
|---|---|---|
| Ink | `#09171f` | logo text, text on amber |
| Red | `#c7171a` | logo only |
| Orange | `#f9650c` | logo; UI uses darker `#b3470a` / `#9a3b05` for AA text/buttons on light |
| Amber | `#fdba0f` | logo; primary button + accents on dark |
| Cream | `#f8f5ee` | page background, icon tiles, theme-color |

Contrast (checked): light accent `#b3470a` = 5.0:1 on page bg, white-on-button 5.5:1; dark accent `#fdba0f` = 10.3:1.

## Rules
- The symbol’s navy disappears on dark UI → always place it on the cream tile (`.brand-mark`).
- On dark backgrounds use the `-dark` wordmark/lockup (ink recoloured to cream; red/orange/amber unchanged).
- Minimum size: symbol 16 px (favicon), wordmark 80 px wide. Keep clear space ≥ the height of the “L”.
- Do not recolour, stretch, add shadows or place the full-colour wordmark on orange/red.

## Known limitation
The supplied kit is **raster** (extracted from a generated concept). It is sharp up to ~1000 px but not vector-clean; ask for an SVG master before print/signage and regenerate the derivatives.
