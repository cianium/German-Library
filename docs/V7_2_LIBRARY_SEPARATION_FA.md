# تفکیک کتاب‌های درسی و کتابخانه مستقل — V7.2.0

## مدل محصول

- سطح (A1–C2) → کتاب اصلی و کتاب‌های دیگر → بستهٔ کتاب → Kursbuch / Arbeitsbuch / Audio / Podcast / Video / Transcript و سایر فایل‌های همان کتاب.
- منابع مستقل تکمیلی همان سطح، در بخش تمرین مهارت و پیشنهادهای منتخب سطح نمایش داده می‌شوند؛ هم‌زمان در `resources.html` قابل جست‌وجو هستند.
- `resources.html` تنها منابعی با `collection=level` و `courseId` خالی را نشان می‌دهد، به‌جز Kursbuch/Arbeitsbuch/Book که نباید بدون بسته کتاب منتشر شوند.
- کتاب‌های چندسطحی و فایل‌های وابستهٔ آن‌ها در `special.html` و صفحه بسته مربوط باقی می‌مانند. سطح جعلی ساخته نمی‌شود.

## قرارداد داده

- برای هر فایل مرتبط با کتاب، `courseId` باید به شناسهٔ Book Package همان سطح اشاره کند.
- Audio و Podcast مستقل، وقتی واقعاً به هیچ کتابی وابسته نیستند، می‌توانند به‌عنوان منبع مستقل بدون `courseId` ثبت شوند.
- برای متن‌ها می‌توان از `Audio Transcript`، `Podcast Transcript`، `Video Transcript` و `Transcript` قدیمی استفاده کرد. متن مرتبط با کتاب باید دارای `courseId` باشد. این نسخه رابطه مستقل بین یک فایل صوتی و متن همان فایل ایجاد نمی‌کند؛ همه در بسته کتاب گروه‌بندی می‌شوند.
- هیچ لینک، ویدیو، فایل کتاب یا Transcript جدیدی به محتوای Seed اضافه نشده است.

## آزمون

`npm run qa` و `npm run release:check` با مقادیر غیرواقعی محیط صرفاً برای تأیید Build اجرا شدند. آزمون اتصال زنده Supabase و اجرای E2E مرورگر در محیط فعلی تأیید نشد.

## قبل از انتشار

- کد را با Production Environment Variables موجود در پروژه Vercel بسازید؛ لازم نیست SQL فعلی دوباره اجرا شود.
- در پنل مدیر نمونه‌ای از Audio Transcript و Video Transcript مرتبط با یک کتاب اضافه و Preview آن را بررسی کنید.
- جست‌وجوی منابع مستقل، بسته کتاب A2، منوهای B1 بدون Core Book، موبایل و لینک‌های برگشت را در Production بررسی کنید.
- در این مرحله redesign بصری و لینک شبکه‌های اجتماعی اجرا نشده‌اند.
